# Math Adventure

An interactive multiplication and division learning app designed for children, with special features for kids with ADHD.

## Features

### Educational Approach (Research-Based)
- **Visual Learning**: Array grids and equal groups help children visualize multiplication and division
- **Adaptive Difficulty**: Problems adjust based on performance - struggling facts appear more often
- **Spaced Repetition**: The app tracks which facts need more practice
- **Strategic Learning Order**: Starts with easier tables (2, 5, 10) before harder ones

### ADHD-Friendly Design
- **Clean, Minimal Interface**: Reduces visual distractions
- **One Problem at a Time**: No overwhelming lists
- **Short Sessions**: Configurable session length (5-20 problems)
- **Break Reminders**: Automatic prompts to take breaks
- **Focus Mode**: Strips UI to essentials
- **Toggleable Animations & Sounds**: Can be turned off if distracting

### Gamification
- **Points & Streaks**: Earn points for correct answers, bonus for streaks
- **Achievement Badges**: Unlock badges for milestones
- **Level Progression**: Level up as you earn points
- **Progress Tracking**: Visual progress bar and statistics

### Accessibility
- **Large Text Mode**: Increases font sizes
- **High Contrast Mode**: Better visibility
- **Keyboard Support**: Navigate with Enter key
- **No Time Pressure**: Work at your own pace

## How to Use

1. Open `index.html` in any modern web browser
2. Enter your name and click "Start Learning!"
3. Solve multiplication and division problems
4. Use the Settings to customize your experience

## Settings

- **Practice Type**: Multiplication only, Division only, or Mixed
- **Times Tables**: Beginner (2,5,10) to Expert (2-12)
- **Session Length**: 5, 10, 15, or 20 problems
- **Break Reminder**: Every 10, 15, or 20 minutes
- **Visual Helpers**: Show/hide array visualizations
- **Focus Mode**: Minimal UI for fewer distractions

## Tips for Parents

1. **Start with Beginner mode** (2, 5, 10 tables) and progress gradually
2. **Keep sessions short** - 10-15 minutes is ideal, especially for ADHD
3. **Enable break reminders** to prevent fatigue
4. **Try Focus Mode** if your child gets distracted easily
5. **Celebrate badges** - they're designed to motivate!

## Technical Details

- Pure HTML, CSS, and JavaScript - no dependencies
- Works offline once loaded
- Progress saved in browser localStorage
- Responsive design for tablets and phones
